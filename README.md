## About

I'm a Computer Engineering student at **Addis Ababa University** and a software engineer who builds full-stack systems with a backend-first mindset. I'm focused on building software products for the Ethiopian and wider African market, starting from how real people and businesses actually work today.

**Right now**
- 🏛️ **Backend Developer Intern, College of Technology and Built Environment (AAU)**, since July 2026: building the production backend for **LENS**, a campus Wi-Fi quality and mobility system planned for ~20,000 students and staff
- 📡 Built the **Calibrator**, an offline and online data-collection app that has handled 1,000,000+ requests, and greatly assisted data collection pipeline of the whole project, projected to have morethan 20,000 user.

**Before**
- 💼 **Junior Full-Stack Developer, [Lumen Labs](https://www.lumenlabs.site)** (Oct 2025 – Jun 2026): client ERP systems, a futsal booking SaaS and a dental clinic management system

**What I care about:** clean API design, secure authentication, real-time systems, and databases that don't fall over. I also like turning what non-technical users say into a product that fits them.

- 🔧 Backend services with Spring Boot, Node.js, Express and Prisma
- ⚡ Real-time systems using WebSockets, STOMP and Socket.IO
- 🔐 JWT authentication, RBAC, and protected route patterns
- 🐳 Docker, Linux, VPS deployment, Supabase and REST-first architecture
- 📱 Mobile apps with React Native
- 🤖 AI-powered features: RAG pipelines and LLM integration

## Projects

### 📡 LENS — Campus Wi-Fi Quality & Mobility System
`Spring Boot` `C` `React Native` `Express` `Prisma` `PostgreSQL` `Supabase`

Production backend for AAU's College of Technology and Built Environment, planned for ~20,000 students and staff. I contributed to the algorithms (speed testing, comparing speed against other users, spot recommendation by purpose), the REST endpoints and the security layer, and I designed and optimized the database to cut request times to the data collection app. I also built the **Calibrator** mobile app (React Native) for offline and online data collection, which has handled 1,000,000+ requests. Mobile app, backend and database each run on their own VPS.

---

### 🦷 Dental Clinic Management System
`Express` `TypeScript` `Prisma` `PostgreSQL` `Socket.IO` `Next.js`

Role-based system for a real dental clinic in Ethiopia, covering patient registration, appointments, treatment, invoicing, payment and follow-up, with real-time dentist notifications. I built the backend for administration, reception and financial management (users, patients, appointments, invoices, payments, audit logs). Built at Lumen Labs with a co-developer and a frontend team.

---

### ⛽ E-Fuel — Fuel Queue Management System
`React Native` `Next.js` `Node.js` `Express` `PostgreSQL` `Supabase`

Built to reduce Ethiopia's long fuel station queues. Three interfaces: a **government admin dashboard** for monitoring distribution and controlling pricing, a **station manager dashboard** for managing availability and bookings, and a **mobile app** for users to find stations, book slots, and get real-time queue notifications.

→ [fuel-management-backend](https://github.com/mame534424/fuel-management-backend)

---

### 💬 Buna ChatApp — Real-Time Messaging Platform
`Spring Boot` `React` `WebSocket/STOMP` `MySQL` `JWT` `AWS S3`

Ethiopian-style messaging platform with live message delivery, RBAC, media sharing, and secure JWT auth. Modular Spring Boot backend designed for throughput and low latency, with an LLM assistant built in.

→ [Backend](https://github.com/mame534424/buna-chatapp) · [Frontend](https://github.com/mame534424/buna-chatapp-frontend-)

---

### 🧠 Smart Transformer Health Monitoring System

AI-assisted monitoring system that uses a retrieval-augmented generation (RAG) pipeline to answer questions about transformer health data.
