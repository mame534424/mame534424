## About

I'm a 3rd-year Computer Engineering student who builds full-stack systems with a backend-first mindset. I've shipped real work — currently contributing to production web applications at **Lumen Labs** in Addis Ababa.

My focus: clean API design, secure authentication, real-time systems, and databases that don't fall over.

- 🔧 Backend services with Spring Boot, Node.js, and Express
- ⚡ Real-time systems using WebSockets and STOMP
- 🔐 JWT authentication, RBAC, and protected route patterns
- 🐳 Docker, Supabase, and REST-first architecture
- 📱 Mobile apps with React Native

## Projects

### ⛽ E-Fuel — Fuel Queue Management System
`React Native` `React` `Node.js` `Express` `PostgreSQL` `Supabase`

Built to reduce Ethiopia's long fuel station queues. Three interfaces: a **government admin dashboard** for monitoring distribution and controlling pricing, a **station manager dashboard** for managing availability and bookings, and a **mobile app** for users to find stations, book slots, and get real-time queue notifications.

→ [fuel-management-backend](https://github.com/mame534424/fuel-management-backend)

---

### 💬 Buna ChatApp — Real-Time Messaging Platform
`Spring Boot` `React` `WebSocket/STOMP` `MySQL` `JWT`

Ethiopian-style messaging platform with live message delivery, RBAC, media sharing, and secure JWT auth. Modular Spring Boot backend designed for throughput and low latency.

→ [Backend](https://github.com/mame534424/buna-chatapp) · [Frontend](https://github.com/mame534424/buna-chatapp-frontend-)

---

### 🛒 Kdame — Full-Stack E-Commerce Platform
`React` `Express.js` `PostgreSQL`

Product browsing, cart management, and user auth — RESTful APIs with optimised database queries.

→ [Repo](https://github.com/mame534424/FUTURE_FS_02)
